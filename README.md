### 💼 Experience

**AI/ML Intern, [ISRO ISTRAC](https://www.istrac.gov.in/)** · *Jan 2026 – May 2026 · Bengaluru*<br/>
*Deep learning for radar-based weather nowcasting*
- Built an end-to-end Python pipeline (PyART, NumPy, SciPy) that ingests, validates, grids and preprocesses **489 volumetric NetCDF radar scans** into training sequences
- Designed and trained a **two-layer ConvGRU in PyTorch** with a residual prediction head to forecast radar reflectivity
- Reached **Pearson r = 0.82**, **2.15 dBZ MAE** and **0.55 CSI** (10 dBZ threshold) on held-out validation data
